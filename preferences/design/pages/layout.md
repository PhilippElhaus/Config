# Layout

- Use tight, even gaps between related items. Leave a small, visible gap
  between the header and the main content and at panel boundaries.
- Keep related summaries in one aligned row on desktop and tablet when
  they fit. Match the heights and edges of adjacent panels. Let the row
  reflow on a narrow screen.
- Match a grid to the number of items. Size controls and tiles to what
  they contain. Use spare width for the content that benefits from it.
- For a dashboard designed around a fixed display, keep the overall
  footprint when adding a panel. Make room by shrinking or removing the
  lowest-value sections.

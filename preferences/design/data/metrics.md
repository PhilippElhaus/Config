# Metrics

- Show measured values where available. Use realistic quantities and
  label estimates, missing data, and completed results distinctly.
- Put the result of a calculation and its inputs together. Show the
  gross value, itemized costs, and net result in one place when they
  determine a decision. Mark an unknown cost explicitly.
- Use consistent units, precision, and date ranges across comparisons.
  Label calendar and rolling windows clearly. Keep related totals together
  and use separators for long numbers.
- Use a compact table for exact comparisons and a chart when the trend
  matters. Keep the current result prominent and the longer history
  available.

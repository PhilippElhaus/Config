# Icons

- Use simple symbols with a clear silhouette at their actual display
  size. Use monochrome line icons for quiet actions and color where it
  carries state or helps recognition.
- Give a new tool its own recognizable icon within the surrounding style.
- Use familiar icons for common actions such as refresh, copy, clear,
  and download. Give them short action labels on hover or focus. Keep
  visible wording for actions whose meaning needs it.

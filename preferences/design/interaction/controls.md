# Controls

- Give equivalent filter bars and selectors the same appearance and
  behavior across related views. Keep scope selectors and common actions
  on one row when space permits.
- Place actions near the data they affect. Put row actions on the row
  and shared actions by the relevant section. Keep a single clear entry
  point for each filter or action.
- Use a context menu for occasional actions on a row or item. Make the
  action's scope clear. Ask for confirmation before permanent deletion.
- Keep dropdowns steady while I move from the trigger to the options.
  Support arrow-key navigation and keep important controls reachable
  when the panel narrows.
- Make the result of a toggle visible on the control. Give inactive,
  selected, and unavailable states distinguishable appearances.
- Show role-specific controls to users with the matching role. When an
  action normally available to the user is temporarily disabled, make the
  reason easy to find.
- Give controls quiet resting states. Use a hover or focus background
  to show which control is ready to act.

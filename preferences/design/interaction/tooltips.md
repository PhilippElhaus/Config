# Tooltips

- Cut text that repeats a label, icon, color cue, or another visible
  explanation. Keep the main result, relevant warning, and next action
  visible without opening anything.
- Put useful secondary detail behind the indicator it explains. Good
  examples include the exact update time on a status pill and a unit
  conversion on a value. Use an info icon when there is no natural target.
- Write tooltips in short lines. Wrap the text, keep the box close to
  its target, and give it enough spacing to read comfortably. Use the
  same disclosure on focus or tap when the surface supports those inputs.

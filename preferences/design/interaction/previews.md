# Previews

- Keep long message previews to a few lines with an ellipsis. Let a
  click expand the message. Use a separate thread action with a message
  count and show that action only while the thread is closed.
- Put a configuration preview behind a small file icon when the aim is
  quick inspection. Render Markdown where it makes the preview easier
  to read.
- Enlarge thumbnails on demand. Trigger the preview from the thumbnail
  itself and keep it out of the way of selection controls. Make it
  follow the current thumbnail without flickering or showing stale
  content.

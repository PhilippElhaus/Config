# Delivery

- When I ask for an answer first, answer and wait for my go-ahead before
  editing. For an authorized change, implement it and run the relevant
  checks. Resolve routine failures within the approved scope.
- Follow the requested scope for local edits, commits, pushes, and each
  deployment target. When I ask to review a change first, provide a
  local preview where practical and wait at the agreed review point.
- When deployment is in scope, follow the pipeline through completion.
  Check the expected revision or artifact at the authorized target and
  run a smoke check through its normal entry point.
